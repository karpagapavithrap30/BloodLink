💡 Registration Tips

📌 A donor who last donated within 90 days will be marked In Cooldown automatically.

📱 Phone number is used as the unique identifier — no duplicates allowed.

📅 If last donation date is left blank, the donor is immediately listed as Available.

🔄 The system runs a daily job at midnight to automatically re-enable donors after cooldown.

💉 Record a Donation

Donor ID is required.
Hospital name is required.
Donation date is required.
⚠️ Cooldown Rule

A donor must wait at least 90 days between donations.

Recording a donation when the donor is still in cooldown returns a 409 Conflict with the exact eligibility date.

After recording, the donor is automatically set to In Cooldown and won't appear in search results.
